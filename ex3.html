Beginner Exercise 03

CSS Selectors & Specificity

Demonstrating how structural pseudo-classes (:first-child, :nth-child(even)), attribute selectors ([data-status]), and hover states target specific elements without extra utility classes.

Solution Code

/* Specific pseudo-classes & attributes */
.ex3-item:first-child {
  border-left: 6px solid var(--color-primary);
  font-weight: 700;
}

.ex3-item:nth-child(even) {
  background-color: var(--color-surface-alt);
}

.ex3-item[data-status="completed"]::after {
  content: " ✓ Completed";
  color: var(--color-success);
  font-weight: 700;
}

.ex3-item:hover {
  transform: translateX(6px);
}
