Intermediate Exercise 10

Transitions & Micro-interactions

Implementing fluid UI micro-interactions using CSS transition with custom easing curves (cubic-bezier), transform elevations, and dynamic icon rotation on hover.

Solution Code

/* Smooth Micro-interactions */
.ex10-card {
  transition: transform 0.3s cubic-bezier(0.34, 1.56, 0.64, 1),
              box-shadow 0.3s ease;
  cursor: pointer;
}

.ex10-card:hover {
  transform: translateY(-8px) scale(1.02);
  box-shadow: var(--shadow-xl);
}

.ex10-card:hover .ex10-icon {
  transform: rotate(15deg) scale(1.15);
}
