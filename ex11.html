Challenging Exercise 11

CSS Grid Portfolio Gallery

Constructing an asymmetric portfolio gallery layout using CSS Grid properties: grid-template-columns: repeat(3, 1fr), cell spanning (grid-column: span 2, grid-row: span 2), and responsive breakpoint degradation.

Solution Code

/* Asymmetric CSS Grid */
.ex11-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: var(--space-4);
}

/* Featured Hero Cell Spanning */
.ex11-item.featured {
  grid-column: span 2;
  grid-row: span 2;
}
