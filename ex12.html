Challenging Exercise 12

Holy Grail Layout (CSS Grid)

Implementing the classic Holy Grail web application layout (Header, Left Navigation, Main Content, Right Aside, Footer) cleanly with grid-template-areas and responsive stacking.

Solution Code

/* Holy Grail Grid Template Areas */
.ex12-holygrail {
  display: grid;
  grid-template-areas:
    "hg-header hg-header hg-header"
    "hg-nav    hg-main   hg-aside"
    "hg-footer hg-footer hg-footer";
  grid-template-columns: 160px 1fr 160px;
  grid-template-rows: auto 1fr auto;
  gap: var(--space-2);
}

.ex12-header { grid-area: hg-header; }
.ex12-nav    { grid-area: hg-nav; }
.ex12-main   { grid-area: hg-main; }
.ex12-aside  { grid-area: hg-aside; }
.ex12-footer { grid-area: hg-footer; }
