Beginner Exercise 01

Typography & Text Styling

This exercise demonstrates the use of CSS font stacks, letter spacing, line height ratios, text transforms, and typographical hierarchy for clean, readable content.

Solution Code

/* CSS Rules */
.ex1-heading {
  font-size: 2rem;
  letter-spacing: -0.03em;
  text-transform: capitalize;
  color: var(--color-text-main);
}

.ex1-subheading {
  font-size: 1.25rem;
  font-style: italic;
  color: var(--color-text-muted);
}

.ex1-lead {
  font-size: 1.15rem;
  line-height: 1.8;
  color: var(--color-text-main);
}

.ex1-tag {
  font-family: var(--font-family-mono);
  font-size: 0.8rem;
  text-transform: uppercase;
  letter-spacing: 0.1em;
}
