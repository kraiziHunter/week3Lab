Intermediate Exercise 07

Responsive Pricing Cards

Constructing a 3-tier pricing layout using Flexbox wrapping, flex-basis sizing, equal-height column distribution, and a featured card state that scales up slightly to draw user focus.

Solution Code

/* Flexbox Pricing Grid */
.ex7-pricing-grid {
  display: flex;
  flex-wrap: wrap;
  gap: var(--space-6);
  justify-content: center;
}

.ex7-card {
  flex: 1 1 260px;
  max-width: 320px;
  display: flex;
  flex-direction: column;
}

.ex7-card.featured {
  border-color: var(--color-primary);
  transform: scale(1.03);
}
