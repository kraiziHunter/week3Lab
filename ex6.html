Intermediate Exercise 06

Flexbox Navigation Bar

Implementing a fully responsive navbar with brand logo on the left, centered navigation links, and call-to-action buttons on the right using Flexbox alignment properties (justify-content: space-between, align-items: center).

Solution Code

/* Flexbox Nav Architecture */
.ex6-nav-demo {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: var(--space-4);
  background-color: var(--color-surface);
  padding: 0.75rem 1.25rem;
}

.ex6-nav-links {
  display: flex;
  list-style: none;
  gap: 1.5rem;
  align-items: center;
}

.ex6-actions {
  display: flex;
  gap: 0.5rem;
}
