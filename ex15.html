Challenging Exercise 15

Theme System & Dark Mode

Architecting a centralized CSS design token palette using CSS Custom Properties and automatic dark mode synchronization via @media (prefers-color-scheme: dark) without any client-side JavaScript.

Solution Code

/* Theme Token Architecture */
:root {
  --color-bg: #f8fafc;
  --color-surface: #ffffff;
  --color-text-main: #0f172a;
}

/* Automatic Dark Mode Media Query */
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #0b0f19;
    --color-surface: #131b2e;
    --color-text-main: #f8fafc;
  }
}
