Beginner Exercise 05

Buttons & Interactive Links

Constructing accessible, versatile button components: solid primary, outline, rounded pill styles, accompanied by keyboard focus indicators and tactile hover micro-interactions.

Solution Code

/* Reusable Button Variants */
.ex5-btn {
  display: inline-flex;
  align-items: center;
  padding: 0.65rem 1.35rem;
  border-radius: var(--radius-md);
  font-weight: 600;
  cursor: pointer;
  transition: all var(--transition-fast);
}

.ex5-btn-primary {
  background-color: var(--color-primary);
  color: #ffffff;
}

.ex5-btn-primary:hover {
  background-color: var(--color-primary-hover);
  transform: translateY(-1px);
}

.ex5-btn-outline {
  border: 1px solid var(--color-border);
  background: transparent;
}

.ex5-btn-pill {
  border-radius: 9999px;
  background-color: var(--color-success);
  color: #ffffff;
}
