Beginner Exercise 04

Colors, Gradients & Backgrounds

Exploring modern CSS color capabilities: multi-stop angled linear gradients, radial accents, and color harmony techniques using CSS custom properties.

Solution Code

/* Gradient Definitions */
.ex4-linear {
  background: linear-gradient(135deg, #6366f1 0%, #a855f7 50%, #ec4899 100%);
}

.ex4-radial {
  background: radial-gradient(circle at center, #38bdf8 0%, #1e40af 100%);
}

.ex4-mesh {
  background: linear-gradient(45deg, #10b981 0%, #06b6d4 100%);
}

Radial Center Sky Blue to Deep Blue
