Challenging Exercise 14

Pure CSS Interactive Accordion

Constructing an accessible, JavaScript-free accordion using native semantic <details> and <summary> elements, custom disclosure markers, and animated content states.

Solution Code

/* Semantic details & summary styling */
.ex14-details {
  border: 1px solid var(--color-border);
  border-radius: var(--radius-md);
  background-color: var(--color-surface);
  overflow: hidden;
}

.ex14-details[open] {
  border-color: var(--color-primary);
}

.ex14-summary {
  padding: var(--space-4);
  font-weight: 700;
  cursor: pointer;
  user-select: none;
}

.ex14-content {
  padding: var(--space-4);
  border-top: 1px solid var(--color-border);
}

What is Semantic HTML5 and why is it required?
Semantic HTML introduces tags like <header>, <nav>, <main>, <article>, and <footer> that clearly describe their meaning to both the browser and screen readers, making websites accessible and SEO-friendly.
How does the CSS Box Model calculate total element size?
With default content-box, total width equals content width + padding + border. With border-box, padding and border are absorbed inside the specified width, making responsive sizing much more intuitive.
When should I choose Flexbox vs. CSS Grid?
Flexbox is optimized for 1-dimensional layouts (a single row or a single column like navbars or button groups), whereas CSS Grid is designed for 2-dimensional layouts where alignment across both rows and columns is needed simultaneously.
