Intermediate Exercise 08

CSS Positioning & Badges

Demonstrating relative parent containers paired with absolute-positioned child elements (notification pill badges, ribbon tags) and sticky layout elements.

Solution Code

/* Relative Parent Container */
.ex8-card {
  position: relative;
  background-color: var(--color-surface);
  border: 1px solid var(--color-border);
  padding: var(--space-5);
}

/* Absolute Floating Badge */
.ex8-badge-absolute {
  position: absolute;
  top: -10px;
  right: 14px;
  background: var(--color-danger);
  color: #ffffff;
  padding: 0.2rem 0.6rem;
  border-radius: var(--radius-full);
}
